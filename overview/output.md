# Output: format, notation and results

## Files
| file | content |
|---|---|
| `output/results.md` | all tables (generated by `experiments/summarize.py`, do not edit by hand) |
| `output/noise_robustness.png` | test rollout error vs training noise, HNN and N-ODE |
| `output/best_configs.json` | selected config per (model, embedding) |
| `output/figures/*.png` | presentation figures (`experiments/make_figures.py`): repro, relu_vs_smooth, tuning, noise, control, bilip_bound |
| `output/bilipschitz_capstone_results.pptx` | the progress deck (Google Slides export + results slides, `experiments/make_slides.py`) |
| `experiment/<stage>/<run>/result.json` | one run: `args`, `final` (last logged `Train_MSE`, `val_MSE`, `test_MSE`, `test_Rollout`), `val_Rollout`, `rollout_vs_ic_noise`, `history`, timings |
| `experiment/<stage>/<run>/model.npz` | trained objax variables (`objax.io.load_var_collection`) |

Run names: `{hnn|node}_{inner|bilip}_L{layers}_H{width}_lr{lr}[_{act}][_g{γ-scale}]_noise{σ}_s{seed}`.
Config strings in the tables: `layers-width-lr[, activation][, γ×scale]`, ReLU and upstream γ when omitted.
All errors are the paper's metric (geometric mean of the state relative error over 500 test trajectories × 150
steps, see `eval_metric.md`), mean ± std over seeds 0-2. 290 runs in total (paper 12, search 212, final 8, noise 36, control 22): 35.5 GPU-hours / 532 SU
(l40s 20.8 h, ica100 12.1 h, a100 2.5 h; ~11 GPU-hours of it are the two runs that hung before the solver
step cap was added).

## 1. Paper reproduction (upstream setting 3-100-5e-3, ReLU)
| model | ours (inner product) | paper Table 1 |
|---|---|---|
| HNN | 0.0092 ± 0.0005 | 0.005 ± 0.002 |
| N-ODE | 0.0104 ± 0.0011 | 0.009 ± 0.001 |

The N-ODE matches the paper within one std; the HNN is within 2x (the paper's 3 trials presumably also
varied the data; here the dataset and split are fixed and only the model seed varies). Tuning the baseline
beats the paper: HNN 0.0015 ± 0.0001 (lr 0.03), N-ODE 0.0058 ± 0.0003 (7-200-0.02).

## 2. Bilipschitz embedder after hyperparameter search (clean data, selected by validation)
| model | inner, own best config | bilip, own best config | bilip vs inner |
|---|---|---|---|
| HNN | **0.0015 ± 0.0001** (3-100-0.03, ReLU) | 0.0074 ± 0.0002 (3-200-0.02, SiLU) | 4.9x worse |
| N-ODE | 0.0058 ± 0.0003 (7-200-0.02) | **0.0056 ± 0.0002** (7-200-0.005) | comparable (-3 %) |

- N-ODE: bilipschitz is comparable to the best tuned baseline and better than the paper's number.
- HNN: with the upstream ReLU the bilipschitz HNN is stuck at 0.32; smooth activations bring it to 0.0074
  (43x better, slightly better than the baseline in the paper setting, 0.0092), but it stays ~5x behind the
  tuned baseline. The upstream scalars make the true Hamiltonian exactly linear in
  the features, which the inner-product HNN exploits and the square-root embedding cannot.

## 3. Gaussian noise on the training data (test rollout, clean test set)
Each method with its own selected config:

| model | features | σ=0 | σ=0.01 | σ=0.03 | σ=0.1 |
|---|---|---|---|---|---|
| HNN | inner | 0.0015 | 0.0028 | 0.0075 | 0.0296 |
| HNN | bilip | 0.0074 | 0.0084 | 0.0151 | 0.0537 |
| N-ODE | inner | 0.0058 | 0.0095 | 0.0273 | 0.0814 |
| N-ODE | bilip | **0.0056** | **0.0078** | **0.0170** | **0.0763** |

Same hyperparameters for both embeddings (the bilip-selected ones; separates embedding from tuning):

| model | config | bilip vs inner at σ = 0 / 0.01 / 0.03 / 0.1 |
|---|---|---|
| HNN | 3-200-0.02, SiLU | +23 % / +20 % / -4 % / **-32 %** |
| N-ODE | 7-200-0.005 | **-31 % / -31 % / -39 % / -15 %** |

(negative = bilipschitz has lower error; for these rows the std over 3 seeds is 1-8 % of the mean, so all

## 4. Perturbed test initial conditions (clean training)
All tuned models reach 0.037-0.038 at σ_IC = 0.1 regardless of the embedding: the error is dominated by the
sensitivity of the true (chaotic) pendulum to the initial condition, not by the model. No measurable effect of
the embedding in this test.

## Conclusions
1. The paper is reproduced (N-ODE within 1 std, HNN within 2x) once the upstream Hamiltonian is restored.
2. The bilipschitz embedder works after two fixes that were needed to train it at all: a differentiable JAX
   implementation (thin SVD of X) and, for the HNN, a smooth activation.
3. N-ODE: bilipschitz scalars are as good as the best-tuned inner products on clean data and consistently
   better under training noise (-31 % to -39 % error at equal hyperparameters for σ ≤ 0.03).
4. HNN: on clean data bilipschitz is worse (the inner-product scalars are the "right" coordinates for this
   Hamiltonian); its error grows more slowly with training noise, and at σ = 0.1 it beats the inner product with
   the same hyperparameters (-32 %), but not the separately tuned ReLU baseline (0.0537 vs 0.0296).
5. Caveats: one dataset / split, 3 model seeds, selection on validation; GPU non-determinism gives ~5-10 %
   run-to-run differences for the same seed (e.g. 0.0091 vs 0.0098), comparable to the seed std.
